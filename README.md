# redmi6-homeserver

Превращаем Xiaomi Redmi 6 (4/64, `cereus`, MediaTek Helio P22) в домашний мини-сервер, который работает круглосуточно от зарядки.

Главная задача сервера — хаб беговой дорожки [treadmill-hub](https://github.com/vlad-rey/treadmill-hub). Остальные сервисы не должны ему мешать.

> Статус: **планирование**. См. [docs/PLAN.md](docs/PLAN.md).

## Что здесь будет

- Инструкции: резервная копия прошивки, разблокировка загрузчика, root (Magisk).
- Ограничение заряда батареи (ACC, 40–80 %).
- ADB по Wi-Fi сразу после загрузки.
- Termux: SSH, сервисы, автозапуск.
- Настройка MIUI для работы в режиме сервера.

## ⚠️ Предупреждение

Разблокировка загрузчика стирает все данные телефона. Операции с прошивкой могут вывести устройство из строя. Всё делается на свой риск и только после полной резервной копии.
