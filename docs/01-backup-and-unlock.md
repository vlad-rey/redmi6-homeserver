# S0–S2. Резервная копия, разблокировка, root

> **Черновик.** Команды и пути проверяются на реальном устройстве перед выполнением. Не выполнять шаги, помеченные «проверить», без подтверждения.

## S0. Подготовка (можно начать сразу)

1. Настройки → О телефоне: записать версию MIUI и Android в [PLAN.md](PLAN.md).
2. Включить режим разработчика: 7 раз нажать на «Версия MIUI».
3. Войти в Mi-аккаунт на телефоне.
4. Настройки → Расширенные настройки → Для разработчиков:
   - **Заводская разблокировка** (OEM unlocking) — включить;
   - **Статус Mi Unlock** → «Связать аккаунт с устройством». Для привязки обычно нужны SIM-карта и мобильный интернет (по Wi-Fi привязка может не пройти).
5. Mi Unlock Tool на PC покажет таймер ожидания (обычно 168 ч) при первой попытке разблокировки. Пока идёт ожидание, работаем над протоколом дорожки.

## S1. Полная резервная копия (`mtkclient`) — проверить

Цель: снять все разделы прошивки, чтобы при любой ошибке можно было восстановить телефон.

1. На PC: установить [mtkclient](https://github.com/bkerler/mtkclient) и драйвер UsbDk (для Windows).
2. Выключить телефон. Зажать обе кнопки громкости и подключить USB — телефон должен войти в режим BROM (экран остаётся чёрным).
3. Прочитать все разделы:
   ```bash
   python mtk.py rl backup/
   ```
4. Проверить, что в `backup/` есть разделы (в т. ч. `boot`, `nvram`, `nvdata`, `persist`, `seccfg`) и размеры не нулевые.
5. **Хранить копию вне телефона и вне git**: в ней IMEI и калибровки радиомодуля.

## S2. Разблокировка и root — проверить

1. Скопировать с телефона всё нужное (разблокировка стирает данные).
2. Разблокировка — один из способов:
   - официальный: Mi Unlock Tool после окончания таймера (телефон в режиме fastboot: Vol− + питание);
   - через `mtkclient` (без ожидания) — только после S1 и отдельного подтверждения.
3. Настроить телефон заново, установить Magisk.
4. Извлечь `boot.img` (из резервной копии S1 или из прошивки той же версии), пропатчить в Magisk, прошить:
   ```bash
   fastboot flash boot magisk_patched.img
   ```
5. Проверить root:
   ```bash
   adb shell su -c id
   ```
6. Отключить автообновления MIUI (обновление может снести root).
