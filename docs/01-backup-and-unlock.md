# Резервная копия, разблокировка, root

Путь: **резервная копия через `mtkclient` → официальная разблокировка через Mi Unlock → Magisk** на стоковой MIUI.

| Часть | Что | Когда | Стирает телефон? |
|---|---|---|---|
| A | Подготовка телефона, привязка Mi-аккаунта | сегодня | нет |
| B | Подготовка PC | сегодня | — |
| C | Резервная копия всех разделов | сегодня | нет |
| D | Разблокировка загрузчика | через ~7 дней | **да** |
| E | Root (Magisk) | сразу после D | нет |
| F | Откат, если что-то пошло не так | при необходимости | — |

Источники: [mtkclient](https://github.com/bkerler/mtkclient), [Magisk](https://github.com/topjohnwu/Magisk), [гайд XDA по mtkclient + Magisk](https://xdaforums.com/t/guide-mediatek-windows-only-use-mtkclient-to-root-your-mediatek-device-via-magisk.4709854/).

## A. Телефон: подготовка и привязка (сегодня)

1. **Узнать версию.** Настройки → О телефоне → записать «Версия MIUI» и «Версия Android» в [PLAN.md](PLAN.md). У нашего телефона: MIUI Global 11.0.4.0 (PCGMIXM), Android 9.
2. **Отключить автообновления** (обновление поменяет прошивку, и резервная копия `boot` перестанет подходить для Magisk): Настройки → О телефоне → «Версия MIUI» → ⋮ → Настройки → выключить «Загружать обновления автоматически».
3. **Режим разработчика**: Настройки → О телефоне → 7 раз нажать на «Версия MIUI».
4. **Настройки → Расширенные настройки → Для разработчиков**:
   - «Заводская разблокировка» (OEM unlocking) — **включить**;
   - «Отладка по USB» — **включить**.
5. **Привязать аккаунт** к разблокировке:
   - войти в Mi-аккаунт (Настройки → Mi-аккаунт), если ещё не вошли;
   - вставить SIM-карту, **выключить Wi-Fi, включить мобильный интернет**;
   - Для разработчиков → «Статус Mi Unlock» → «Связать аккаунт и устройство». Должно появиться «Успешно привязано».
6. **Во время ожидания** не выходить из Mi-аккаунта и не привязывать повторно — таймер может начаться заново.

> Таймер ожидания (обычно 168 ч) показывает Mi Unlock Tool при первой попытке разблокировки (часть D, шаги 1–4). Имеет смысл сделать эту первую попытку сразу после резервной копии, чтобы таймер пошёл.

## B. PC: подготовка (сегодня)

Нужно: Windows 10/11, ~20 ГБ свободного места, USB-кабель с передачей данных.

1. **Python 3.12.** `mtkclient` зависит от `keystone-engine`, у которого нет готовых сборок под Python 3.14. Поставить 3.12 рядом с существующим:
   ```bash
   winget install Python.Python.3.12
   ```
2. **Драйвер UsbDk** (64-bit, `.msi`) — скачать с [github.com/daynix/UsbDk/releases](https://github.com/daynix/UsbDk/releases) и установить. Требует прав администратора.
3. **mtkclient** — скрипт клонирует его в `D:\Code\tools\mtkclient` (вне репозиториев) и создаёт окружение на Python 3.12:
   ```bash
   powershell -ExecutionPolicy Bypass -File D:\Code\redmi6-homeserver\tools\setup-mtkclient.ps1
   ```
   Если установка `keystone-engine` всё равно падает — поставить Visual Studio Build Tools с компонентом «Desktop development with C++» и запустить скрипт ещё раз.
4. **Mi Unlock Tool** — скачать с официального сайта Xiaomi: [unlock.update.miui.com](https://unlock.update.miui.com) (эту ссылку показывает сам телефон в «Mi Unlock status»). Страница отдаёт версию 6.5, в которой нет `MiUsbDriver.exe`, а ссылка на обновление внутри программы даёт 403. Рабочий вариант — версия 7.6.727.43 с того же официального сервера: `https://miuirom.xiaomi.com/rom/u1106245679/7.6.727.43/miflash_unlock_en_7.6.727.43.zip` (~114 МБ; сервер рвёт соединение на 10 МБ — докачивать `curl -C -`). Распаковать, запустить `miflash_unlock.exe`, в настройках (шестерёнка) → верхняя кнопка «Check» (установка драйвера) либо напрямую `MiUsbDriver.exe` от администратора. Для резервной копии (часть C) этот драйвер не нужен — только для fastboot.
5. `adb` и `fastboot` уже есть: `C:\Users\vreds\AppData\Local\Android\Sdk\platform-tools\`.

## C. Резервная копия всех разделов (сегодня)

> В копии есть IMEI и калибровки радиомодуля (`nvram`, `nvdata`, `protect*`). Хранить в надёжном месте, никуда не выкладывать. Папка `backup/` закрыта в `.gitignore`.

1. Зарядить телефон минимум до 50 %. **Выключить телефон**, отключить от USB.
2. Запустить резервную копию (скрипт сначала сохранит таблицу разделов, потом прочитает все разделы, кроме `userdata`):
   ```bash
   powershell -ExecutionPolicy Bypass -File D:\Code\redmi6-homeserver\tools\backup-partitions.ps1
   ```
> **Важно:** `mtkclient` должен быть **уже запущен и ждать**, когда вы подключаете телефон. BROM ждёт хост доли секунды; если на PC никто не слушает, телефон грузится дальше — с «Громкость −» в fastboot, с «Громкость +» в MI-Recovery (в нём ничего не выбирать). Скрипт подключается дважды (таблица разделов, затем сами разделы) — между шагами телефон нужно переподключить так же.

3. Когда в консоли появится `Waiting for device` / `Preloader - Waiting`: **зажать обе кнопки громкости** на выключенном телефоне и, не отпуская, **подключить USB-кабель**. Экран остаётся чёрным — это нормально (режим BROM). Кнопки отпустить, когда в консоли пошёл обмен.
   - Не определяется → попробовать только «Громкость +», другой USB-порт (лучше USB 2.0 на задней панели) и другой кабель.
4. Чтение идёт от нескольких минут до получаса. Не трогать кабель.
5. После окончания проверить в `D:\Code\redmi6-homeserver\backup\<дата>\`:
   - есть `gpt.txt` и файлы `*.bin` по разделам;
   - обязательно есть и не пустые: `boot.bin`, `recovery.bin`, `nvram.bin`, `nvdata.bin`, `protect1.bin`, `protect2.bin`, `seccfg.bin`, `lk.bin`, `preloader*.bin`;
   - записать, есть ли `vbmeta.bin` (понадобится в части E).
6. Отключить кабель, зажать кнопку питания на ~10 с, чтобы телефон загрузился нормально.
7. **Скопировать папку копии ещё в одно место** (облако с шифрованием, флешка, другой диск).

## D. Разблокировка загрузчика (через ~7 дней)

> ⚠️ **Стирает все данные на телефоне.** Перед этим: скопировать фото, файлы и логи Bluetooth, если они нужны.

1. Выключить телефон. Зажать **«Громкость −» + «Питание»** до появления зайца (режим fastboot).
2. Подключить телефон к PC.
3. Запустить `miflash_unlock.exe`, войти в тот же Mi-аккаунт, что и на телефоне.
4. Нажать «Unlock».
   - Первая попытка покажет, сколько часов ждать — **так таймер и запускается**. Записать дату.
   - После окончания ожидания повторить шаги 1–4: инструмент разблокирует загрузчик и сотрёт данные.
5. Телефон перезагрузится. При каждом включении будет предупреждение о разблокированном загрузчике — это нормально.
6. Минимально настроить телефон: Wi-Fi, **без** автообновлений (см. A.2), режим разработчика, «Отладка по USB».

## E. Root через Magisk (сразу после D)

1. Проверить, что прошивка не менялась: «Версия MIUI» совпадает с записанной в части A. Иначе `boot.bin` из копии не подходит — написать в чат.
2. Скачать последний `Magisk-vXX.X.apk` с [github.com/topjohnwu/Magisk/releases](https://github.com/topjohnwu/Magisk/releases) и установить:
   ```bash
   adb install Magisk-vXX.X.apk
   ```
3. Передать образ `boot` из копии на телефон:
   ```bash
   adb push D:\Code\redmi6-homeserver\backup\<дата>\boot.bin /sdcard/Download/boot.img
   ```
4. На телефоне: Magisk → Magisk «Установить» → «Выбрать и пропатчить файл» → `Download/boot.img` → «Поехали». Готовый файл: `Download/magisk_patched-XXXXX_XXXXX.img`.
5. Забрать его на PC:
   ```bash
   adb pull /sdcard/Download/ D:\Code\redmi6-homeserver\backup\patched\
   ```
6. Перезагрузить в fastboot и прошить:
   ```bash
   adb reboot bootloader
   fastboot flash boot D:\Code\redmi6-homeserver\backup\patched\magisk_patched-XXXXX_XXXXX.img
   ```
7. **Только если в копии есть `vbmeta.bin`:**
   ```bash
   fastboot --disable-verity --disable-verification flash vbmeta D:\Code\redmi6-homeserver\backup\<дата>\vbmeta.bin
   ```
8. Перезагрузить:
   ```bash
   fastboot reboot
   ```
9. Открыть Magisk. Если попросит «дополнительную настройку» — согласиться, телефон перезагрузится.
10. Проверить root (на телефоне появится запрос Magisk — разрешить):
    ```bash
    adb shell su -c id
    ```
    Ожидается `uid=0(root)`.

## F. Откат

| Проблема | Что делать |
|---|---|
| После прошивки `boot` телефон не загружается | Fastboot (Громкость − + Питание) → `fastboot flash boot <копия>\boot.bin` → `fastboot reboot` |
| Телефон не входит даже в fastboot | Режим BROM (часть C, шаг 3) → `mtk.py w boot <копия>\boot.bin` (выполнять вместе с агентом) |
| Пропал IMEI / сеть | Восстановить `nvram`, `nvdata`, `protect1`, `protect2` из копии через `mtkclient` (выполнять вместе с агентом) |
| Совсем всё плохо | Официальная fastboot-прошивка для `cereus` той же версии + MiFlash |
